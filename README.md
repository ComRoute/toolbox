# Boîte à outils Route / Gereedschapskist voor de Route
Pour publier sur GitHub, créer le dépôt public boite-a-outils-route sous le compte ou l’organisation choisi, y déposer le contenu de cette archive et activer les Issues. Dans Settings → Pages, choisir Deploy from a branch, puis main et /docs. La page Assistance utilise le nom du dépôt sur github.io. Pour un domaine personnalisé, y fixer le lien vers le support.
Les quatre dossiers disposent d’une page permanente dans docs. Ajouter un lien vers le document définitif dans la page concernée. Publier les modèles vierges uniquement.
Koudou permet de chercher un terme dans la copie du lexique fournie et de copier une consigne pour ChatGPT. Tester la traduction en collant la consigne. La copie locale provient de Koudou 0.3.4. Le lien Google ouvre la version tenue à jour.
Pour le plugin, déployer le répertoire service sur un hébergeur Docker HTTPS. Régler PUBLIC_HOST au nom d’hôte public sans protocole et PORT au port attendu. Tester /mcp avec MCP Inspector (initialize, tools/list et appel de rechercher_terme_scout sur routier en fr et voortrekker en nl). Vérifier que la feuille autorise la lecture CSV anonyme. Relire les pages de confidentialité et d’utilisation selon l’hébergeur retenu.
Depuis le dossier décompressé, générer le ZIP de soumission avec python construire_plugin.py URL_HTTPS_DU_SITE URL_HTTPS_DU_SERVICE_MCP. Soumettre le fichier Koudou-0.4.0.zip ainsi obtenu. Cette archive de projet complète est destinée au dépôt GitHub.
